Data Flow

What happens when a user changes a filter on the Dashboard.

  1. User selects a filter in FilterBarTime period, warehouse, category or order status.
  2. useFilters updates shared refsModule-level refs act as a singleton store shared by every view.
  3. View watcher reloads dataThe view calls getCurrentFilters(), which maps location to warehouse and period to month.
  4. api.js builds the requestValues of all are dropped, the rest become query params, for example /api/orders?warehouse=Tokyo&month=Q1-2025.
  5. FastAPI filters in memoryapply_filters() matches warehouse, category and status; filter_by_month() matches month or quarter on order_date.
  6. Pydantic validates the responseresponse_model shapes the JSON returned to the client.
  7. Vue recomputes derived dataRaw data is stored in refs; KPIs, tables and SVG charts are computed properties.

Shared state and utilities

  • useFilters.js - four filter refs at module scope, so all views share one filter state. Exposes getCurrentFilters(), resetFilters() and hasActiveFilters.
  • useI18n.js - English and Japanese locales from locales/, persisted in localStorage.
  • useAuth.js - hard-coded mock user and task list, localized. No real authentication.
  • utils/currency.js - currency formatting.
  • api.js - single Axios client with a hard-coded base URL.
  • App.vue - shell layout, navigation and global styles (slate palette).

Observations

Things found while reading the code that are worth knowing before you change it.

Gap Client calls endpoints the server does not define

api.js has methods for /api/tasks (GET, POST, DELETE, PATCH) and /api/purchase-orders (POST, GET by backlog item). main.py defines neither, so those calls would return 404 or 405. A CreatePurchaseOrderRequest model exists but has no route.

Inconsistency Reports bypasses api.js

Reports.vue imports Axios directly with a hard-coded http://localhost:8001 URL instead of going through the shared client.

Scope Data is read-only and resets on restart

All data lives in Python lists loaded at import. Every route is GET, so nothing is written back, and any future write would be lost on restart.

Security Demo-only configuration

CORS allows all origins, there is no authentication or rate limiting, and the server binds to 0.0.0.0. Fine locally; not suitable for deployment as is.

Maintainability Large view files

Dashboard.vue (1,271 lines) and Spending.vue (852 lines) combine data loading, chart math and markup. They are good candidates for splitting into components.

Testing Backend only

tests/backend covers dashboard, inventory and other endpoints with pytest. There are no frontend unit or end-to-end tests in the repo.
